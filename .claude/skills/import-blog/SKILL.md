# Import Blog from URL

Import, optionally improve, and publish a blog post from an external URL.

The user invokes this as `/import-blog <url>`.

## Steps

### 1. Fetch and parse the URL

Call the import-url API to extract content:

```bash
curl -s -X POST http://localhost:3001/api/admin/import-url \
  -H "Content-Type: application/json" \
  -H "Cookie: admin_session=<get from env or ask user>" \
  -d '{"url": "<USER_PROVIDED_URL>"}'
```

Display the extracted:
- **Title**
- **Excerpt** (first 200 chars)
- **Content** (word count)
- **Cover image** (if found)

### 2. Ask the user

Present options:
1. **Publish as-is** — use the extracted content directly
2. **Improve with AI** — send to `/api/admin/ai-write` with action `improve`
3. **Summarize only** — generate an excerpt via AI
4. **Cancel**

### 3. Select category

Show the available categories and ask the user to pick one:
- Personal Finance Foundations
- Income & Cash Flow Management
- Investment Basics
- Mutual Funds Investing
- Stock Market Investing
- Tax Planning
- Retirement Planning
- Insurance Planning
- Debt Management & Credit Score
- NRI Financial Planning
- Behavioral Finance & Money Psychology
- Market Updates
- General

### 4. Publish

Create the post via the admin API:

```bash
curl -s -X POST http://localhost:3001/api/admin/posts \
  -H "Content-Type: application/json" \
  -H "Cookie: admin_session=<session>" \
  -d '{
    "title": "<title>",
    "slug": "<auto-generated-slug>",
    "excerpt": "<excerpt>",
    "content": "<markdown-content>",
    "cover_image": "<cover_image_url>",
    "category": "<selected-category>",
    "author": "MyFinancial",
    "status": "published"
  }'
```

### 5. Confirm

Display:
- Published URL: `/blog/<slug>`
- Word count and reading time
- Category assigned
