**Asset vs Liability donut chart (D-05):**
- Use Recharts `PieChart` + `Pie` + `Cell` (dynamic imports, ssr: false).
- Two segments: Assets (color: `#10B981`) and Liabilities (color: `#F87171`).

- Wrap in a card with title "Asset vs Liability".

**Category-wise asset breakdown table (D-06):**
- Group assets by `category` field. Sum amounts per category.
- Render as a styled table with columns: Category, Amount, % of Total.
- Sort descending by amount.
- Use palette colors for rows (alternating s1/s2 backgrounds).

**12-month projection chart (D-07, D-08, D-09, D-10, D-11):**
- Build projection data: array of 13 points (month 0 = now, month 12 = end).
- For each month:
  - `projectedAssets = totalAssets * (1 + 0.08/12)^month` (8% p.a. compounded monthly per D-08)
  - `projectedLiabilities = totalLiabilities - (totalMonthlyEMI * month)` but floor at 0 (liabilities decrease by EMI payments per D-08). Calculate `totalMonthlyEMI` as sum of all `liability.emi`.
  - `projectedNetWorth = projectedAssets - projectedLiabilities`
- Chart: Recharts `AreaChart` with `ResponsiveContainer`.
  - X-axis: month names (use `new Date(now.getFullYear(), now.getMonth() + i).toLocaleString('default', { month: 'short' })`)
  - Single Area for projected net worth, stroke `#10B981`, gradient fill like goals page.
  - Tooltip: month name + `formatCurrency(value, true)` (per D-10).
  - Add a ReferenceLine or dashed Area at current net worth for comparison (per D-09 — "current net worth point").
- Below chart: disclaimer text "Projected based on current portfolio and EMI schedule" in muted text (per D-11).
