# Phase 9.1: Retirement Corpus SWP Autofill — Context

**Gathered:** 2026-04-12
**Status:** Ready for planning
**Source:** User requirement (INSERTED phase)

<domain>
## Phase Boundary

Enhance the Step 4 Retirement Goal autofill panel: make retirement age editable, calculate total retirement corpus from EPF/PPF/NPS and retirement-term instruments, apply the 3% annual withdrawal rule to derive monthly SWP income, and autofill this into the Retirement Goal.

**Key rule:** If user's current age >= retirement age, they are already retired. Sum all retirement corpus instruments = 100% available corpus. Monthly income = (corpus x 3%) / 12 via SWP.

</domain>

<decisions>
## Implementation Decisions

### Editable Retirement Age
- **D-01:** Retirement age displayed in the Step 4 retirement panel becomes an editable number input (currently read-only from backend `retirementData.retirementAge`)
- **D-02:** Default value: backend's `retirementAge` (typically 60). User can adjust between 50-75
- **D-03:** Changing retirement age recalculates all derived values (corpus needed, SIP required, years left, SWP income)
- **D-04:** Updated retirement age is sent to the backend profile via `POST /api/v1/profile` to persist

### Retirement Corpus Calculation (Age >= Retirement Age)
- **D-05:** When user's current age >= retirement age, they are considered "retired"
- **D-06:** Retirement corpus = sum of all assets where:
  - subCategory contains "EPF" (🏢 EPF (Provident Fund))
  - subCategory contains "PPF" (📈 PPF (Public Provident Fund))
  - subCategory contains "NPS" (🎯 NPS (National Pension System))
  - timeHorizon === "Retirement" (any instrument tagged with retirement term)
- **D-07:** Data source: `useAssessmentStore` assets array — already available client-side from Step 3
- **D-08:** Show corpus breakdown in the retirement panel: EPF amount, PPF amount, NPS amount, other retirement instruments, total

### 3% SWP Withdrawal Rule
- **D-09:** Annual withdrawal = total retirement corpus × 3%
- **D-10:** Monthly SWP income = annual withdrawal / 12
- **D-11:** Display: "Your monthly retirement income via SWP: Rs. X" prominently in the panel
- **D-12:** This replaces the "SIP Required" section when user is already retired (no SIP needed if already retired)

### Autofill Into Retirement Goal
- **D-13:** When retirement panel is active, autofill the retirement goal fields:
  - For pre-retirement (age < retirementAge): autofill target corpus, SIP amount, horizon from backend data (existing behavior)
  - For retired (age >= retirementAge): autofill monthly income (SWP amount), show corpus as "achieved"
- **D-14:** The retirement goal card should show a different state for retired users: "Retirement Corpus: Rs. X | Monthly SWP: Rs. Y" instead of "Target: Rs. X | SIP: Rs. Y/mo"

### UI Changes
- **D-15:** Retirement age input: inline number field with +/- stepper buttons, styled to match the panel
- **D-16:** Retired state: green badge "Retired" next to the age display, corpus breakdown table, SWP income highlight
- **D-17:** Pre-retirement state: existing panel behavior (corpus required, gap, SIP plans) — unchanged

### Claude's Discretion
- Exact styling of the editable retirement age input
- Animation/transition when switching between pre-retirement and retired states
- Whether to show a "Congratulations" message for retired users

</decisions>
