Export the `TourStep` interface:
```typescript
export interface TourStep {
    targetId: string;
    title: string;
    body: string;
    placement: "top" | "bottom" | "left" | "right";
}
```

Export the `useTour` hook with this signature:
```typescript
export function useTour({ steps, storageKey }: { steps: TourStep[]; storageKey: string }): {
    active: boolean;
    stepIndex: number;
    step: TourStep;
    totalSteps: number;
    next: () => void;
    skip: () => void;
}
```

Implementation details:
- `active` state initializes from a function: if `typeof window === "undefined"` return false. Otherwise try `localStorage.getItem(storageKey) !== "done"`, catch returns false (fail-safe: do not show tour if storage unavailable).
- `stepIndex` state starts at 0.
- `next` callback: if `stepIndex + 1 >= steps.length`, call `localStorage.setItem(storageKey, "done")` inside try/catch, then `setActive(false)`. Otherwise increment stepIndex.
- `skip` callback: call `localStorage.setItem(storageKey, "done")` inside try/catch, then `setActive(false)`.
- Return `{ active, stepIndex, step: steps[stepIndex], totalSteps: steps.length, next, skip }`.
- Use `useState` and `useCallback` from React. Follow the exact localStorage try/catch pattern from `useStreak.ts`.

Helper function to extract userId from user_profile cookie (for storage key construction by consumers):
```typescript
export function getTourUserId(): string {
    try {
        const match = document.cookie.match(/user_profile=([^;]+)/);
        if (!match) return "anon";
        const parsed = JSON.parse(decodeURIComponent(match[1]));
        return parsed.id || parsed.email || "anon";
    } catch {
        return "anon";
    }
}
```

**File 1: `src/components/onboarding/coach-mark-tooltip.tsx`**

`"use client"` component. Imports `useAppTheme` from `@/hooks/useAppTheme` and `TourStep` from `@/hooks/onboarding/useTour`.

Props interface:
```typescript
interface CoachMarkTooltipProps {
    step: TourStep;
    stepIndex: number;
    totalSteps: number;
    onNext: () => void;
    onSkip: () => void;
}
```

Implementation:
- Use `useState` for `pos` (`{ top: number; left: number }`), initialize to `{ top: -9999, left: -9999 }` (offscreen until positioned).
- Use `useState(false)` for `visible` (opacity fade-in gate).
- Use `useRef<HTMLButtonElement>(null)` for the Next/Done button to manage focus.
- Get palette via `const palette = useAppTheme();`.

`useEffect` keyed on `[step.targetId]`:
1. Find target: `const el = document.getElementById(step.targetId);` If null, call `onNext()` to skip missing elements and return.
2. Save previous styles: `const prevShadow = el.style.boxShadow; const prevZIndex = el.style.zIndex; const prevPosition = el.style.position; const prevBorderRadius = el.style.borderRadius; const prevTransition = el.style.transition;`
3. Apply spotlight: `el.style.boxShadow = "0 0 0 9999px rgba(8,14,18,0.80)"; el.style.borderRadius = "8px"; el.style.position = "relative"; el.style.zIndex = "10001"; el.style.transition = "box-shadow 200ms ease";`
4. Scroll: `el.scrollIntoView({ behavior: "smooth", block: "center" });`
5. After 100ms setTimeout, calculate position from `el.getBoundingClientRect()`:
   - For all placements, position tooltip with `position: "fixed"` using viewport-relative rect values.
   - `top` placement: `top = rect.top - tooltipHeight - 12` (12px gap)
   - `bottom` placement: `top = rect.bottom + 12`
   - `left` placement: `top = rect.top + rect.height/2 - tooltipHeight/2; left = rect.left - 320 - 12`
   - `right` placement: `top = rect.top + rect.height/2 - tooltipHeight/2; left = rect.right + 12`
   - Default horizontal center: `left = rect.left + rect.width / 2 - 160`
   - Clamp left: `Math.max(16, Math.min(left, window.innerWidth - 336))`
   - Clamp top: `Math.max(16, Math.min(top, window.innerHeight - 250))`
   - Set `pos` state, then set `visible(true)`.
6. Focus the Next/Done button ref after positioning.
7. Cleanup function: restore all saved styles on the element.

Add a `ResizeObserver` on the target element inside the same useEffect. On resize, recalculate position using the same logic. Disconnect observer in cleanup.

Render via `ReactDOM.createPortal` into `document.body`:
- Outer div: `position: "fixed"` at computed `pos.top`/`pos.left`, `width: 320`, `background: palette.s1`, `border: "1px solid " + palette.brd`, `borderRadius: 12`, `padding: "16px 24px"`, `zIndex: 10002`, `color: palette.txt`, `fontFamily: "var(--font-display)"`, `boxShadow: "0 20px 60px rgba(0,0,0,0.5)"`, `opacity: visible ? 1 : 0`, `transition: "opacity 150ms ease-in"`.
- Step counter `<p>`: `color: palette.accent`, `fontSize: 11`, `fontWeight: 600`, `lineHeight: 1.2`, `marginBottom: 4`. Text: `Step ${stepIndex + 1} of ${totalSteps}`.
- Title `<p>`: `fontSize: 16`, `fontWeight: 600`, `lineHeight: 1.25`, `marginBottom: 8`, `color: palette.txt`. Text: `{step.title}`.
- Body `<p>`: `color: palette.txt2`, `fontSize: 14`, `fontWeight: 400`, `lineHeight: 1.5`. Text: `{step.body}`.
- Button row `<div>`: `display: "flex"`, `justifyContent: "space-between"`, `alignItems: "center"`, `marginTop: 16`.
- Skip button: `background: "none"`, `border: "none"`, `color: palette.mute`, `fontSize: 12`, `cursor: "pointer"`, `padding: "8px 0"`, `minHeight: 44`. Text: "Skip tour". onClick: `onSkip`.
