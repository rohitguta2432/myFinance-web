## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Step counter | 11px | 600 (semibold) | 1.2 | "Step 2 of 5" label above title |
| Tooltip title | 16px | 600 (semibold) | 1.25 | Tooltip heading |
| Tooltip body | 14px | 400 (regular) | 1.5 | Explanatory copy inside tooltip |
| Button label | 14px | 600 (semibold) | 1.0 | "Next" and "Done" CTA buttons |
| Skip link | 12px | 400 (regular) | 1.0 | "Skip tour" text button |

Exactly 2 weights in use: 400 (regular) and 600 (semibold). The tooltip title's 16px size provides hierarchy differentiation from body at 14px — weight 700 is not needed and has been removed.

All text uses `fontFamily: "var(--font-display)"`.

Source: Typography sizes match existing dashboard usage at 11px (muted labels), 14px (body), 16px (primary text). Verified from `BenchmarkComparison.tsx` and `ProjectionChartInner.tsx`.

## Z-Index Stack

The tour overlay must sit above all existing UI layers. Verified existing z-index ceiling:

| Layer | Z-index |
|-------|---------|
| Navbar | 100–200 |
| Assessment step sidebar | 50 |
| SectionNav (dashboard) | 40 |
| Kira chat widget | 9999 |
| Inactivity guard overlay | 9999 |
| **Tour spotlight element** | **10001** |
| **Tour tooltip card** | **10002** |

The tour overlay uses the spotlight box-shadow trick (`box-shadow: 0 0 0 9999px rgba(8,14,18,0.80)`) applied directly to the target element — there is no separate full-screen overlay div. This avoids z-index stacking conflicts with the Kira chat widget and inactivity guard at 9999.

Source: Grep of all `zIndex` values in `src/` — highest verified values are 9999 (chat-widget.tsx:289, inactivity-guard.tsx:124).

## Tooltip Card Anatomy

The tooltip card is a single positioned card rendered into `document.body` via `ReactDOM.createPortal`. All measurements are exact.

```
┌─────────────────────────────────────────────┐  ← width: 320px
│  Step 2 of 5                                │  ← 11px, semibold, accent color, mb: 4px
│  Your Financial Health Score                │  ← 16px, semibold, palette.txt, mb: 8px
│  This score is calculated from 5 pillars:   │  ← 14px, regular, palette.txt2, lh: 1.5
│  Liquidity, Protection, Growth,             │
│  Allocation, and Tax.                       │
│                                             │
│  [Skip tour]              [Next →]          │  ← 12px skip / 14px semibold Next
└─────────────────────────────────────────────┘
   padding: 16px 24px | borderRadius: 12px
```

**Card styles (CSSProperties):**
- `width: 320`
- `background: palette.s1`

- `borderRadius: 12`

- `position: "fixed"` — avoids scroll-offset math (Pitfall 5 from RESEARCH.md)
- `zIndex: 10002`
- `color: palette.txt`

**Button "Next"/"Done" styles:**

## Interaction Contract

### Tour Trigger
- Tour activates on component mount if `localStorage.getItem("myfinancial_tour_assessment_${userId}") !== "done"`.
- Gate is checked AFTER data has loaded (`isLoading === false`) to avoid positioning on skeleton elements.
- Tour does NOT activate if localStorage is unavailable (fail-safe: treat as "seen").

### Step Advance
- Clicking "Next" increments the step index and repositions the tooltip to the next target element.
- On the last step, "Next" label changes to "Done". Clicking "Done" marks the tour as seen and removes the tooltip.

### Skip
- Clicking "Skip tour" at any step marks the tour as seen immediately and removes the tooltip.
- No confirmation required — skip is not destructive.

### Keyboard
- "Next"/"Done" button receives focus on step change (`el.focus()` after render).
- Tab moves between "Skip tour" and "Next"/"Done" within the tooltip.
- Escape key closes the tour (marks as seen).

### Positioning
- Tooltip uses `position: "fixed"` (not absolute) to eliminate scroll offset math.
- Position recalculates on window resize via `ResizeObserver` on the target element.
- Tooltip clamps to viewport: if computed left < 16, set left = 16. If computed left + 320 > viewport width - 16, set left = viewport width - 336.

### Spotlight
- Target element receives `boxShadow: "0 0 0 9999px rgba(8,14,18,0.80)"` and `zIndex: 10001` inline.
- On step advance or tour end, previous element's styles are restored to their pre-tour values.

### Scroll
- `el.scrollIntoView({ behavior: "smooth", block: "center" })` is called on each step change to ensure target is visible before tooltip renders.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA — advance | "Next" (steps 1 to N-1) / "Done" (last step) |
| Primary CTA — initial trigger | No trigger button — tour auto-starts on first visit |
| Skip action | "Skip tour" |
| Step counter format | "Step {N} of {total}" — always visible above tooltip title |
| Empty state | Not applicable — tour only renders when active |
| Error state | Not applicable — tour is client-side only; if a target element is missing, silently skip that step (no error shown to user) |
| Destructive actions | None in this phase |

All tooltip `title` and `body` strings are hardcoded static values. No user-generated content, no API data, no interpolated financial figures are rendered inside tooltip text. Security requirement per RESEARCH.md.

## Animation Contract

No external animation library is added. Transitions use CSS only:

| Element | Transition |
|---------|-----------|
| Tooltip card appear | `opacity: 0 → 1` over 150ms ease-in via inline `style.transition` |
| Tooltip card step change | No animation — instant reposition (avoids positioning artifacts mid-transition) |
| Spotlight box-shadow | `transition: "box-shadow 200ms ease"` applied inline to target element |

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| WCAG 2.5.5 touch targets | "Next"/"Done" and "Skip tour" buttons: `minHeight: 44` with `padding: "8px 16px"` / `padding: "8px 0"` |
| Focus management | Focus moves to "Next"/"Done" button on each step render |
| Tab order | Skip → Next (left to right within tooltip, no other focusable elements) |
| Escape key | Closes tour |
| Screen reader | Tooltip card has `role="dialog"` and `aria-label="Onboarding tour"` |
| Color contrast | Step counter (#10B981 on #0C1319): 4.5:1 verified against WCAG AA |
