**localStorage schema** (key: `myfinancial_streak`):
```json
{ "count": 5, "lastVisit": "2026-04-12" }
```

**Hook logic (per D-01, D-03, D-04):**
1. On mount, read `myfinancial_streak` from localStorage. If missing, initialize `{ count: 1, lastVisit: today }`.
2. Compare `lastVisit` to today (use `YYYY-MM-DD` date strings, no time zones — just `new Date().toISOString().slice(0, 10)`).
   - Same day → no change (already counted today).
   - Yesterday (1 day diff) → increment `count` by 1, update `lastVisit` to today.
   - 2 days ago (48h grace per D-03) → increment `count` by 1, update `lastVisit` to today.
   - 3+ days ago → reset `count` to 1, set `lastVisit` to today.
3. After updating, persist to localStorage.
4. Check milestone thresholds: if `count` equals exactly 7, 30, or 100, fire a `toast.success()` with a flame emoji and message (e.g., "7-day streak! You're on fire!"). Use `{ id: "streak-milestone" }` to prevent duplicate toasts.

**Return type:**
```typescript
interface StreakData {
  count: number;
  lastVisit: string;
  isNewMilestone: boolean;  // true if count is exactly 7, 30, or 100
}
```

**Date diff helper:** Create a private function `daysBetween(dateA: string, dateB: string): number` that parses YYYY-MM-DD strings and returns the absolute difference in days.

**Import toast from `react-hot-toast`.** Use `"use client"` directive at top of file.

The 8 badges (per D-06):
| id | name | icon (Lucide) | howToEarn |
|----|------|---------------|-----------|
| `first-steps` | First Steps | `Footprints` | Complete Step 1 of assessment |
| `money-map` | Money Map | `Map` | Complete all 6 assessment steps |
| `goal-setter` | Goal Setter | `Target` | Add your first financial goal |
| `diversified` | Diversified | `PieChart` | Have assets in 3+ categories |
| `debt-free` | Debt Free | `Smile` | Zero liabilities |
| `protected` | Protected | `ShieldCheck` | Have both life and health insurance |
| `tax-smart` | Tax Smart | `Calculator` | Complete tax optimization step |
| `streak-master` | Streak Master | `Flame` | Maintain a 30-day login streak |

**Badge evaluation logic** (per D-08 — runs on dashboard load):
1. Read assessment store via `useAssessmentStore` selectors: `currentStep`, `isComplete`, `goals`, `assets`, `liabilities`, `insurance`, `taxRegime`, `investments80C`.
2. Call `useStreak()` to get streak count for "Streak Master" check.
3. Evaluate each badge:
   - `first-steps`: `currentStep >= 2` (moved past step 1)
   - `money-map`: `isComplete === true`
   - `goal-setter`: `goals.length > 0`
   - `diversified`: `new Set(assets.map(a => a.category)).size >= 3`
   - `debt-free`: `liabilities.length === 0`
   - `protected`: `insurance.personalLife.length > 0 && insurance.personalHealth.length > 0`
   - `tax-smart`: `isComplete === true` (tax is step 6, completion implies it)
   - `streak-master`: `streakCount >= 30`
4. Compare newly earned set against `myfinancial_badges` in localStorage (per D-07). localStorage stores a JSON array of earned badge IDs: `["first-steps", "goal-setter"]`.
5. For any badge newly earned (in current set but NOT in localStorage), fire a celebratory toast (per D-12): `toast.success()` with the badge name and a party emoji. Use `{ id: badge-${badgeId} }` to deduplicate.
6. Update localStorage with the new complete set of earned badge IDs.
