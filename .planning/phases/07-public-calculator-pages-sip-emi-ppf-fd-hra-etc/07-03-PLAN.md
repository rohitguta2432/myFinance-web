Derived:
```typescript
const exemption = calcHRA(basicSalary, hraReceived, rentPaid, isMetro)
```

```typescript
const yearsLast = calcSWP(corpus, monthlyWithdrawal, annualGrowthRate)
```

- LineChart: shows remaining corpus balance over time (year 0 to yearsLast).
  ```typescript
  // Build data points: at each year, remaining balance
  // Simple approximation: balance(yr) = corpus*(1+r)^yr - withdrawal*12*((1+r)^yr - 1)/r
  // where r = annualGrowthRate/100
  const r = annualGrowthRate / 100
  const chartData = Array.from({ length: Math.ceil(yearsLast) + 1 }, (_, i) => {
    const bal = corpus * Math.pow(1 + r, i) - (monthlyWithdrawal * 12) * (Math.pow(1 + r, i) - 1) / r
    return { year: i, balance: Math.max(0, bal) }
  })
  ```
