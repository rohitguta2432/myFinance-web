2. Create `src/lib/pdf-utils.ts` with these exports:

   **Constants:**
   ```typescript
   export const PDF_PAGE_W = 210;   // A4 width in mm
   export const PDF_PAGE_H = 297;   // A4 height in mm
   export const PDF_MARGIN = 14;    // left/right margin in mm
   export const PDF_CONTENT_W = PDF_PAGE_W - PDF_MARGIN * 2; // 182mm
   export const FOOTER_RESERVE = 20; // mm reserved for disclaimer footer
   ```

   **formatForPdf(value: number): string** — Converts number to Indian compact currency with "Rs." prefix (NOT rupee symbol). Logic:
   - `>= 1e7` -> `Rs. X.XX Cr`
   - `>= 1e5` -> `Rs. X.XX L`
   - else -> `Rs. X,XX,XXX` (Indian grouping via `toLocaleString("en-IN")`)
   - Handle NaN/undefined -> return "Rs. 0"

   **checkPageBreak(doc: jsPDF, currentY: number, neededHeight: number): number** — If `currentY + neededHeight > PDF_PAGE_H - FOOTER_RESERVE`, calls `doc.addPage()` and returns 20 (top margin on new page). Otherwise returns `currentY`. The `doc` parameter type should be `{ addPage: () => void }` to avoid importing jsPDF at module level.

   **captureChartAsImage(elementId: string): Promise<{ dataUrl: string; aspectRatio: number } | null>** — Async function that:
   - Gets DOM element by ID, returns null if not found
   - Dynamically imports html2canvas: `const html2canvas = (await import("html2canvas")).default`
   - Calls `html2canvas(el, { backgroundColor: "#ffffff", scale: 2, useCORS: true, logging: false, removeContainer: true })`
   - Returns `{ dataUrl: canvas.toDataURL("image/png"), aspectRatio: canvas.height / canvas.width }`

   **addBrandedHeader(doc: jsPDF, title: string): void** — Draws the green header bar on current page:
   - `doc.setFillColor(16, 185, 129)` (#10B981)
   - `doc.rect(0, 0, PDF_PAGE_W, 22, "F")`
   - White text, helvetica bold, size 13: `"MyFinancial — " + title` at x=MARGIN, y=14
   - Type for doc: use `any` since jsPDF is dynamically imported

   **addDisclaimerFooter(doc: jsPDF): void** — Iterates all pages and adds footer:
   - For each page `i` from 1 to `doc.getNumberOfPages()`:
     - `doc.setPage(i)`
     - Draw light gray line at y = PAGE_H - 14
     - Set font size 7, color #64748B
     - Text: "This report is for informational purposes only and does not constitute financial advice. Past performance is not indicative of future results."
     - Right-aligned page number: "Page i of N"

   **getDateString(): string** — Returns YYYYMMDD format: `new Date().toISOString().slice(0, 10).replace(/-/g, "")`

   **getFormattedDate(): string** — Returns human-readable date: `new Date().toLocaleDateString("en-IN", { day: "2-digit", month: "long", year: "numeric" })`

   IMPORTANT: No top-level imports of jspdf or html2canvas. All browser-dependent code must be behind dynamic imports or accept the doc instance as a parameter.
