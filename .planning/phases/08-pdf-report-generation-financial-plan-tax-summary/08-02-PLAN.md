**Helper: computeAssetAllocation(assets: AssetItem[]):**
- Group assets by `category` field
- Sum `amount` per category
- Compute totalAssets = sum of all amounts
- Return array of `{ category, amount, percentage: (amount / totalAssets) * 100 }` sorted by amount desc
- If totalAssets is 0, return empty array

**Helper: computeNetWorth(assets: AssetItem[], liabilities: LiabilityItem[]):**
- totalAssets = sum of assets.map(a => a.amount)
- totalLiabilities = sum of liabilities.map(l => l.balance)
- return totalAssets - totalLiabilities

**Helper: computeMonthlySurplus(incomes: IncomeItem[], expenses: ExpenseItem[]):**
- totalMonthlyIncome = sum of incomes.map(i => annualize(i) / 12) — handle frequency: "monthly" * 1, "yearly" / 12
- totalMonthlyExpenses = sum of expenses.map(e => annualize(e) / 12) — handle frequency similarly
- return totalMonthlyIncome - totalMonthlyExpenses
- NOTE: If the GoalProjection response has `monthlySurplus`, prefer that over local computation as it uses backend logic
